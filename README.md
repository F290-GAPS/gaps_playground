# Configurações Primordiais para o GitHub Projects

A ferramenta do GitHub Projects é uma ferramenta incrível para a gestão ágil de projetos de software. Ela permite que equipe de desenvolvimento organize e gerenciem seu projeto de software de forma mais eficiente.

Para começar a usar o GitHub Projects é necessário criar um novo projeto clicando no botão "New project" no seu repositório.

## Criar um novo projeto no GitHub Projects

Ao criar um novo projeto, você pode nomear o projeto e adicionar um quadro Kanban para organizar suas tarefas.

## Nomear e adicionar quadro Kanban

Depois de criar o projeto, você pode adicionar colunas e quadrinhos para organizar suas tarefas. Por exemplo, você pode ter colunas para "To do", "In progress" e "Done".

## Adicionar colunas e quadrinhos

Além disso, o GitHub Projects permite que você adicione labels para categorizar suas tarefas.

## Adicionar labels

Para adicionar tarefas ao projeto, você pode criar um issue ou um pull request e adicionar o projeto como um destino.

## Adicionar um projeto como um destino

Além disso, o GitHub Projects permite que você adicione marcos para rastrear o progresso do seu projeto.

## Adicionar marcos

Para adicionar um marco, você pode clicar no botão "Add milestone" e nomear o marco.

## Adicionar um marco

Por fim, é importante que as configurações do GitHub Projects sejam definidas corretamente para o bom andamento do trabalho em equipe.

- Os colaboradores devem ser convidados para o projeto.
- As labels devem ser definidas para categorizar as tarefas.
- Os marcos devem ser definidos para rastrear o progresso do projeto.
- As tarefas devem ser atribuídas a um colaborador.
- As tarefas devem ser atribuídas a um quadro Kanban.
- As tarefas devem ser atribuídas a um marco.

Essas são apenas algumas configurações primordiais para o GitHub Projects. Caso você precise de mais informações, consulte a [documentação oficial](https://docs.github.com/pt/github/managing-your-work-on-github/about-projects).
